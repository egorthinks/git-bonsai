# 🏛 Bonsai Hall of Fame

Trees grown from the **public** GitHub history of people whose work shaped
how we all write software. Same rules as everyone: nothing here is drawn by
hand — every trunk, scar and blossom is earned.

> 🌱 **First harvest pending.** The gallery is generated by
> `node scripts/hall-of-fame.js --token <PAT>` — it fetches the public metrics
> of the roster below, caches them under `fixtures/hall/` (so every render is
> reproducible bit-for-bit) and rewrites this file with the trees.
